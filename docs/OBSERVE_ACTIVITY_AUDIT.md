# Observe Live activity repair

Date: 2026-10-11. Contract: 1.108. User priority: verify the actual activity feed before resuming routed purchasing.

The production reproduction returned fifty events with descending=false: registrations were pinned above newer trade events. Human signups were excluded, wallet sources were absent, numeric-text dates were not normalized before source limits, and source failures could report a successful empty or partial timeline. Evidence: `/tmp/clawdmarket-observe-production-before.log`.

The public feed now merges public agent registrations (including awaiting claim), agent-account signups, privacy-safe human signups, public trades/ratings/improvements, recorded public market payments, the already published canonical MPP-on-Tempo platform proofs and confirmed payouts/refunds. Each source reads its latest fifty records using millisecond-normalized SQLite ordering, then one stable chronological merge returns the latest fifty events. Numbers and numeric text support Unix seconds/milliseconds; offset-free SQLite dates are UTC; ISO offsets preserve their instant. Full UTC dates are visible alongside relative times and exposed in `<time datetime>`. No registration priority overrides chronology.

A private, no-store `/api/wallet/activity` overlay reads only the authenticated caller's credit-ledger entries and confirmed external payouts/refunds. Anonymous viewers receive no private activity, and request parameters cannot select another account. Deposits appear when the backed-credit entry is posted, not when an unpaid intent is created. Submitted transfers are not confirmed events. Original private order visibility remains enforced. Human registrations omit names/email/raw account IDs; private events and trade transaction summaries omit payer/recipient addresses, hashes, serialized transactions, signatures and original private references. Public platform proof IDs reuse their already published transaction hash to deduplicate historical/stored evidence. Personal events clear on logout refresh, failed authorization/storage checks, focus and visibility changes; superseded private responses cannot restore them.

Activity refresh remains independent of telemetry every five seconds. An unavailable public source returns 503 and the browser keeps its last complete snapshot with “refresh delayed”. Private activity clears when it cannot be rechecked. The feed is explicitly the latest fifty events, not an exhaustive historical export. Legacy completed trades without completion timestamps and disputed trades retain their recorded creation date because the original storage has no authoritative dispute-opening timestamp.
